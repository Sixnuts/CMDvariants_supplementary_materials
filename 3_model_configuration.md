# Models and Experimental Period
The Act–Judge framework was developed using Qwen-Plus (`qwen-plus`) and Qwen-VL-Plus (`qwen-vl-plus`), two closed-source models provided by Alibaba Cloud and accessed through API calls. 

Development, debugging and experiments involving the agent framework were carried out mainly between November 2025 and February 2026. Selected prompts, implementations of the three CMD variants and representative experimental records are provided as supplementary materials to help readers understand the study and explore further developments of the framework.

Further advances in language and vision-language models may create opportunities for new decomposition formulations, analytical derivations and multimodal assessment strategies. We hope these materials provide a useful reference for researchers exploring new ideas in physics-constrained PolSAR decomposition.
